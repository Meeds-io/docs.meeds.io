# Managing Spaces

### :busts\_in\_silhouette: Who can manage all spaces?

* Only Administrators can access this Spaces Management Feature

### &#x20;:tools: How to access the Spaces Management Page?

* Access the Platform Settings
* Go to Organization Entry from the Administration Menu
* Access to Spaces

### :question: What are the options?

The Spaces Management Page list any space created in the platform, including those you are not member of. From there, here are the informations suggested

* Space Identity
  * You can click to it to access the space
* Last Activity Information
  * You need to be member of the group "Analytics Administrator"
* Template
  * The Template Icon is reminded to know what the template is
  * Hovering the icon tells you about the template name
* Admins list
  * You can list them in a drawer
  * From there, feel free to contact admins
* Users
  * Find here the total number of members in the space
* Sync
  * If green, that means a group is [synchronized ](bind-a-space-to-a-group-of-users.md)with the space. Group members are automatically members of this space
  * If grey, that means no synchronization is running for this space

**Access the 3 dots suggested for each space item to list options**

* Open Settings: Access settings of the space to help space admins out
* Sync Settings: Manage Synchronization between group members and space membership
* Apply Template: Apply a template to this space&#x20;
* Save as Template: Save the space as a template
* Permissions: Update permissions for one space
* Delete: Delete the space and any content listed there

:bulb: **In case you need to do an action for multiple spaces, select a list of spaces and options will be suggested accordingly**
