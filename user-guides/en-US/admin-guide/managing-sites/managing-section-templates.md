# Create Section Templates

### :busts\_in\_silhouette: Who can add Section Templates?

* Only Administrators can create a template
* Either when editing a page, either when managing templates

### &#x20;:tools: How to manage section templates?

* Access the Platform Settings
* Go to Development Entry from the Administration Menu
* Access to Templates > Sections
* Choose whether you want to create or edit a template

### :question: What are the options?

When creating / editing a template, you will be able to:

1. Select from which section type you want to start (dynamic or fixed)
2. Identify the skeleton of your sections (columns and/or rows)
3. Add applications
4. Customize their styling & preferences
5. Preview the display for Mobile View

Once ready, you can save it and following infos wil be request to fill:

* Name
* Description
* Preview

:bulb: **The Preview is automatically generated once you save your template**

#### Using of a section template

When editing a page, you can add as many sections as you want. Hence, to help you creating pages in few clicks, we provide you the section templates you can create as precised above.

Once added in your page, feel free to update it as your convenience.&#x20;

#### Cloning of a section

In case you want to clone a section within the same page, access the options of the section from its top-right. You will be invited to clone it.  Once cloned, it is added below the original section, with all previously added applications and applied styles.
