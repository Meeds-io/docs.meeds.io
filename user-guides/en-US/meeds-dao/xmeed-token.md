# ⚖️ xMEED Token

xMEED is the governance token of Meeds DAO. It is obtained by staking [MEED](meed-token.md) tokens on out vault.\


To learn more about staking read : [https:///www.meeds.io/staking](https://www.meeds.io/staking)



The xMEED token lives on Ethereum mainnet at [https://etherscan.io/token/0x44D6d6aB50401Dd846336e9C706A492f06E1Bcd4](https://etherscan.io/token/0x44D6d6aB50401Dd846336e9C706A492f06E1Bcd4)



use xMEED to vote on Meeds DAO Governance on [Snapshot](https://snapshot.box/#/s:meedsdao.eth)
